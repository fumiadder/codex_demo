# 知序 · 个人工作台

应用源码位于 `workbench/`，包含独立账号、空间协作、工作／生活分区、私密密码箱、录音和媒体展示。生活类别下的“睡前小故事”进入晚安故事模块，电脑支持三栏预览，手机使用竖版界面。服务器保存用户数据，仓库只包含代码和虚构测试资料。

晚安故事使用奶黄暖光、夜间护眼模式与同站中文字体，内置 14 篇原创故事、六类题材和约 1／5 分钟分级。支持分段逐句朗读、高亮和分页、可关闭的温和提问、固定安抚结尾、收藏和历史、钢琴／白噪音，以及 30／60／90 分钟定时关闭和休眠唤醒。故事文本与音色独立，切换音色保留正文。通用 `/bedtime.html?panel=voices` 链接在登录后进入用户自己的音色上传页；未连接云服务时提供设备朗读和素材本机试听。

个性化故事生成对接百炼 `qwen-plus`，支持年龄、时长、风格、主角和互动偏好；真实克隆与联网故事检索也需配置服务端接口。缺少密钥时明确关闭相应能力，不显示伪造生成或训练结果。配置与接口见 `workbench/BEDTIME.md`。

正式部署采用 Linux 服务器、Docker Compose 和 Caddy HTTPS，数据库、上传文件和证书使用持久化卷。配置与首次上线步骤见 `workbench/DEPLOY-PRODUCTION.md`。后续 `main` 提交经过检查，由 GitHub Actions 发布到已配置的同一正式服务器；服务器未配置时会明确跳过部署。

免费测试站：https://zhixu-free-test.onrender.com 。它会休眠且可能清空数据，仅用于体验；正式环境与测试站独立。该站关闭自动部署，目前仍是第一版；代码提交不代表新功能已经上线，现有站点更新步骤见 `workbench/DEPLOY-FREE.md`。验证记录见 `workbench/VERIFICATION.md`。
