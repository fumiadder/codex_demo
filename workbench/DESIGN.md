# 知序：界面设计与扩展原则

面向个人长期使用的中文工作台。每天先快速捕捉想法，再整理任务和记录；工作与生活使用独立过滤视图，共享由空间成员权限决定。

色彩：墨绿 #254E41 用于导航和主操作，纸白 #F7F8F5 用于工作背景，墨字 #24382F 用于文字，草灰 #879089 用于次要信息，浅叶 #EAF0E9 用于状态，麦穗 #C49B5A 用于生活提示。文字采用本地中文字体栈，无外部字体请求；标题用有分量的中文字号，正文保持清晰层级。

布局：桌面 232px 侧栏承载空间与功能入口，顶部工作／生活切换。主区域以宽任务列、窄快速记录、横向笔记与媒体架形成不同信息密度，避免所有内容等大的卡片。生活分区使用暖纸色并加大任务间距。移动端收起侧栏。入口和保存结果使用同一操作词；「知」印章是主要品牌特征。

主操作为记录与完成任务；协作成员与密码箱按明确的访问边界展示。真实账号初始为空，样例数据只用于标明演示的体验模式。人工智能工具在模块库标明待配置，不返回伪造模型结果。

本轮使用官方 find-skills、frontend-design 和内置 Sites 指引。长期扩展通过 item 类型、空间权限与明确的独立 API 实现；添加模型服务、日历或账本时必须沿用后端授权，不把模型密钥发送到浏览器。

晚安故事按用户指定的床头暖灯方向独立使用奶黄 #FFF6E6、豆沙 #F8D9D0、薄荷 #D8E9E4、棕灰 #4A3F35 与米色分隔线 #EADCC7。背景采用奶黄向浅粉的径向渐变，卡片统一 24px 圆角；标题和操作留白比故事元信息更宽，正文阅读区居中。夜间模式采用约为日间 80% 亮度的暖色背景，正文和控件字号统一增加 10%，保留文字对比以便阅读。

字体来自随站部署的真实 Noto Sans SC 变量 WOFF2，不向字体 CDN 请求。正文使用 400、标题使用 500；正文 1.95 行高与 2px 字距，主要标题采用 5px 字距。故事生成卡片默认展示年龄、分类与时长，风格、主角与温和提问收进偏好，避免睡前首页信息过密。桌面保留故事库、阅读区、右侧播放器三栏，手机改为竖版和带安全区的底部毛玻璃播放器；语音控制仅保留一组 DOM。

微弱星点保持静态；仅实际朗读时，阅读卡片以 12 秒周期轻微呼吸，停止朗读即停止。系统减少动态效果偏好会关闭所有动画和过渡。问题区采用薄荷底，继续按钮清楚表达返回故事；到达睡眠定时后使用无闪烁暖棕休眠遮罩，提供键盘可达的返回按钮。设备合成轻柔钢琴音与白噪音在设置中明确标示来源；克隆、生成及联网搜索仍根据真实服务配置启用，不用界面模拟服务完成。
