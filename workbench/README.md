# 知序 · 个人工作台

中文个人工作台。独立账号与空间权限、工作／生活分区、任务和笔记、浏览器加密密码箱、媒体上传与预览、录音保存，以及移动端“晚安故事”模块。页面不依赖外部字体、CDN 或第三方登录，可部署在国内云节点；实际国内访问需部署后实测。

## 本地运行

需要 Python 3.12 或以上，无第三方 Python 包。

```bash
python server.py
```

打开 `http://localhost:8000` 并注册自己的账号。启动默认绑定地址和端口以服务输出为准。实际数据位于 `DATA_DIR` 指定的目录；默认本地 `data/`，此目录已从代码和部署包中排除。真实账号不会写入演示样例。

```bash
python -m unittest discover -s tests -v
node --check public/app.js
node --check public/bedtime.js
```

浏览器与容器验证详情见 `VERIFICATION.md`。可重复浏览器检查需要开发环境额外提供 Playwright 与 Chromium，生产运行不依赖它们。

免费公网测试采用 Render Free Web Service，新加坡区域，配置见 `render.yaml` 与 `DEPLOY-FREE.md`。它保留真实后端与空间权限，但免费文件系统可能在休眠或重启后清空，只用于测试数据。`WORKSPACE_TEST_MODE=1` 会在登录页和工作台显示测试环境提示。

已发布测试站：https://zhixu-free-test.onrender.com 。它仍运行原测试版本，新晚安故事和正式发布流程尚未部署到该地址。原版本 12 组真实公网检查记录：https://github.com/fumiadder/codex_demo/actions/runs/37613219063 。国内可达性尚未独立验证。

## 国内云部署

可使用阿里云、腾讯云等提供的 Linux 云服务器。准备一个域名并将 DNS A 记录解析到服务器；按所选国内云厂商要求完成备案。开放 TCP 80、443；应用端口 8000 仅在 Docker 内部使用。此仓库不包含或创建云账号、付费资源、域名和备案。

首次部署和后续自动更新按 [DEPLOY-PRODUCTION.md](DEPLOY-PRODUCTION.md) 执行：服务器环境配置保存在 `/srv/zhixu/shared/.env`，源码使用不可变提交目录，数据库、媒体和 HTTPS 证书使用固定持久化卷。正式环境采用邀请注册，首次管理员通过 `scripts/manage_access.py` 创建一次性注册邀请码。

后续 `main` 提交通过 Workbench CI 后，GitHub Actions 自动发布到同一已配置的服务器。发布前备份，健康检查失败回退应用镜像并保留新写入；未配置服务器凭据时明确报告“未部署”。数据库结构变化需准备兼容迁移，目前发布守卫会拒绝未经处理的结构变化。

Caddy 为已正确解析的域名申请 HTTPS 证书。Docker 镜像获取和证书签发需要网络连通性。`TRUST_PROXY=1` 仅用于 Compose 中应用被 Caddy 隔离的场景；不要将应用端口直接暴露到公网并信任任意代理头。

证书签发及健康检查成功后，用两个真实账号验证独立空间、邀请、只读权限、媒体上传和播放，以及同一账号换设备后的数据同步。浏览器录音和 Web Crypto 密码箱要求 HTTPS 或 localhost。部署尚未执行时不能把本地验证当作国内网络验收。

## 长期免费云存储

支持已有 Render Free 网站接入 Neon Free 原生 PostgreSQL 和私有 S3 媒体桶，存储独立于应用的临时磁盘。配置、迁移保护、免费额度、邀请码、备份及上线验收见 [Neon 操作指南](docs/neon-migration.md)。数据库存账号、空间、记录、密码箱密文及故事收藏历史；私有桶存上传附件和短期朗读缓存。当前云资源已建，但旧数据与公网切换尚未完成。切换不自动迁移或清空旧数据，配置错误不自动退回 SQLite。

## 数据与访问

- 每个账号有自己的空间。注册其他账号不会获得既有空间访问权。
- 空间所有者可按已注册成员的邮箱授予编辑或只读权限。协作不会改变成员各自的个人空间。
- 工作／生活是空间内记录的分区。共享一个空间会共享该空间内普通工作、生活记录；只想共享工作时应单独创建协作空间，把个人生活记录保留在个人空间。
- 密码箱按用户和空间保存浏览器生成的密文，不与普通协作成员共享。PBKDF2 与 AES-GCM 在浏览器执行，密码和明文不会发送给服务器。密码忘记后无法恢复内容；登录账号并不能解密密码箱。
- 用户账号密码只保存加盐派生值；服务器使用 HttpOnly 会话 Cookie、同源请求校验、空间成员授权和上传大小限制。文件下载也检查权限。
- 文件存储位于本地持久化卷，单个上传上限 25 MiB，默认每空间累计 1 GiB、全站 10 GiB，保留至少 100 MiB 磁盘余量。图片、音视频、PDF 可以预览；其他文件以安全下载提供。服务器运维者对普通记录和媒体具有基础设施层面的访问能力。
- 每账号最多 50 个自有空间，每空间最多 2000 条普通记录；达到容量时会提示，列表不会静默丢弃记录。部署方可通过 `MAX_SPACE_STORAGE_BYTES` 和 `MAX_TOTAL_STORAGE_BYTES` 调整文件总量。

## 语音与扩展

语音录入提供真实录音、试听和保存。自动转写使用浏览器支持的 SpeechRecognition，支持度和识别服务连通性由浏览器决定；它可能将语音发送到浏览器厂商服务。未支持时仍可录音并手动补充文字。部署方可按需接入国内语音识别服务。

模块库保留后续扩展入口，AI 模型、日历、账本等未配置项应明确展示待接入状态。本版没有伪造 AI 回复，也不会把模型密钥放进前端。接入模型、云语音或第三方应用时，将凭据配置在服务端并复用空间权限校验。

## 晚安故事

在工作台切到“生活”，从“睡前小故事”卡片、侧栏生活专区或模块库进入“晚安故事”。PC 采用故事列表、阅读正文与常驻播放器三栏；手机保持竖屏布局。奶黄暖光界面、同站中文字体与夜间字号放大适配电脑和手机。故事文本与朗读音色独立，同一篇正文切换音色不会重新搜索。内置 14 篇完整原创故事，覆盖六类和约 1／5 分钟分级；支持分段逐句朗读、高亮、可关闭的温和提问、固定安抚结尾、设备声音、背景钢琴音与白噪音、收藏及上次故事。30／60／90 分钟定时可渐弱，到期停止声音并进入可唤醒休眠页。主动选择的故事文本可按账号和空间保存到当前设备，并下载 TXT；离线重新打开站点及锁屏持续朗读取决于浏览器，未提供完整原生离线 APP。

分享音色上传入口 `/bedtime.html?panel=voices`，首次使用者登录或注册后直达自己的上传窗口。链接不携带私人音色或空间信息。未配置云服务时可以选择 10–30 秒录音在本机试听；配置后，确认素材授权并创建真实克隆音色，成功后自动选中该音色，点击播放即可朗读当前故事。上传入口会检查当前账号与空间权限，单纯点击分享链接不会获得其他人的音色或数据。

个性化生成对接百炼，默认 `qwen-plus`，可由服务端明确选择 `qwen3.8-flash`；故事与云端语音可分别关闭，便于按已核对的模型额度分阶段接入。可传年龄、类型、时长、风格、主角及互动偏好；生成后点击朗读，不自动播放或保存正文。真实音色克隆支持 Qwen Audio 3.1 的免费音色创建接口：上传 10–30 秒音频并确认授权后，可保存多个音色档案，使用已核对的语音合成额度朗读；已有旧 Qwen 配置保持兼容。新路线使用业务空间 API Host 和私有 S3 临时签名样本，处理后清理，不公开存储桶。联网检索对接 OpenSearch 或 Tavily。服务端未配置密钥时明确显示待连接，默认使用原创故事和设备音色。云端合成和检索仍受供应商额度、有效期及计费规则约束。配置、接口、数据流与实际限制见 [BEDTIME.md](BEDTIME.md)。

## 备份与维护

默认 SQLite 方案的数据和媒体持久化于 `zhixu_data` 卷；Neon 模式使用云端数据库与私有对象存储，必须另做 PostgreSQL 和对象备份，不能用本地卷备份替代。备份脚本短暂停止应用，验证 SQLite 和完整文件清单后恢复运行；恢复操作使用新的独立卷，拒绝覆盖现有卷。具体命令见生产部署文档，容器实测见 [OPS-VERIFICATION.md](OPS-VERIFICATION.md)。备份包含私人记录、媒体和密码箱密文，应放到受控存储并另做加密异地备份。不要使用 `docker compose down -v` 删除卷。

不要修改运行中的数据库或共享文件目录。需要大规模协作、审计、恶意文件扫描、密码重置、邮箱验证或高可用时，应在这版基础上扩展。
