# 章节匹配规则（lib/names.mjs）

## 归一化 normalize
NFKC 全角转半角 → 去空白 → 去全部方括号装饰注释（【更新】、[课件]、〖资料〗等，支持多个）→ 去标点（保留圆括号内文字，如“上/下”）→ 小写。

## 装饰前缀预处理
extractIndex/stripIndex 先调用 stripDecor 去掉装饰块再解析序号，因此 `【更新】01 导论` 与 `第1章 导论` 可正确高置信匹配，不会误报闸门。

## 序号提取 extractIndex
支持：第N章/讲/节/课/篇（含中文数字，cnToInt 支持到百）、`N-M` 子节、`03、`/`03. `/`03 ` 前缀。

## 相似度
- Dice 双字组系数、编辑距离比率、包含比率三者取最大；
- 序号一致时加权（≥0.75 基线），序号冲突时强压（≤0.59，名称几乎完全相同也不自动配）；
- 主体 ≤3 字时额外收紧，防“导论/导言”误配。

## 置信度阈值（保守）
- high ≥ 0.86 且无近似对手 → 可自动发布；
- medium 0.62–0.86 → 必须人工确认；
- ambiguous：高分但存在 0.12 分差内的 rival → 必须人工确认；
- none < 0.62 → 人工指定或跳过。

## 调参
阈值在 names.mjs 的 `THRESH`；改动后必须重跑 names.test.mjs 的黄金样例（正常/序号错位/完全不同/近似标题/装饰前缀）。

## 增量判重 diffNewChapters
纯函数，按 fsid 与归一化名双重判重：改名（fsid 不变）、重新上传（新 fsid 同名）、装饰差异均不算新增，保证每日订阅零重复转存。

## orphan-share
网盘存在但网站目录无对应的文件夹（加餐/资料包）进入 pending-gates 的 orphan-share 项，仅提示不阻塞，默认不发布。
