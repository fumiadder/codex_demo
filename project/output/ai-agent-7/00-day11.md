## 1.2 vibe coding

```python
# 1 翻译过来：氛围编程，感觉编程，是 2025 年初由前 OpenAI 研究科学家提出、并被 评为年度热词的AI 原生编程范式。

# 2 一句话：你用自然语言说 “我要什么效果”，AI 帮你写代码；你只管看结果、提修改，不用逐行手写

# 3 核心思想：角色彻底反转
传统编程【古法编程】：人写代码、机器执行；人要懂语法、逻辑、细节、调试。
Vibe Coding：人定意图、AI 实现；人是 产品经理，AI 是程序员。

# 4 典型流程（5 步）
1 描述需求：用日常语言说清功能 / 效果，如 “做一个待办 App，支持增删改查和深色模式”。
2 AI 生成代码：LLM（GPT-4o/Claude/Cursor）直接输出可运行项目。
3 运行验证：一键跑起来，看是否符合预期。
4 迭代调优：用自然语言提修改（如 “按钮放右边、加加载动画”），AI 自动改代码。
5 最终交付：关键场景做安全 / 性能审计，上线

# 5 常用工具
编辑器：Cursor、Windsurf、GitHub Copilot Chat、VS Code + Copilot,Trae等
模型：GPT-4o、Claude 3、Gemini Advanced、DeepSeek V2。
平台：vibe-coding.run（官方演示站）：https://vibe-coding.run/zh

# 6 一句话总结【更利于小白】
Vibe Coding = 自然语言当代码，AI 当程序员，你当产品经理。它不是取代编程，而是重新定义人机分工，让创意落地更快、门槛更低
```
