## 火神AI中转站

火神AI：https://huoshenai.net/register?aff=GLJNCRL4DL6T

简单说，它帮你**用一个接口，调用很多种AI模型**。你可以把它想象成一个“AI模型的万能插座”。

它主要解决两个麻烦：

1. **不用挨个对接**：你不需要分别去OpenAI、谷歌、或者国内大模型公司注册账号、看不同的开发文档。接入它一个，就能用很多模型。
2. **更稳定、省钱**：它会管理很多账号和密钥（也就是“账号池”）。如果一个模型访问不了或太慢，它可以**自动切换到另一个**，保证你的服务不停。还能帮你统计每个模型花了多少钱。

**原理**：Codex本身需要连接OpenAI的服务，而通过火神AI这样的中转站，你的请求会先发给国内可直接访问的火神AI服务器，再由它去对接背后的大模型。这样，你就直接在国内网络下使用了。

**基本配置：**

- 登录火神AI后台后，在左侧菜单点击“充值/订阅”。可以选择快捷金额，也可以在自定义金额输入框里填写金额。

- 充值完成后，进入“API 密钥”页面。点击右上角“创建密钥”，按照需要选择分组，创建后页面会出现新的 API 密钥。
- 创建密钥时按实际需求选择分组。不同分组会显示不同倍率，可根据自己的使用场景选择。
