## 1.2 低代码应用是什么

```python
# 1  低代码应用：
	-智能体 -->弱化了--》我们没讲
    	-豆包的智能体在下架
        
    -工作流：一套流程--》学过了
    	-可以在智能体中使用【不管】
        -可以在低代码应用中使用---》我们要学的
    -低代码应用：我们正常写软件，需要编写代码---》低代码应用指的是不需要写代码，仅仅通过拖拖拽拽，就能创建出一款软件[网站软件，手机端软件：微信小程序]
    
# 2 老师认为：低代码应用目前是小白最合适的编软件的平台

# 3 Coze对话编程
	-我们通过提示词[跟ai交互]，让ai帮我们写代码--》写出软件--》可控性很低
    	-页面样子，功能：是ai自己设计并写完的
        
    -低代码应用：我们不写代码，我们拖拖拽拽可视化--》写出软件
    	-对于小白更直观，更可控
        -界面样子，我们设计的
        -功能流程：我们设计的
        -制作过程，不耗费资源地
        
# 4 低代码应用是什么
是字节跳动推出的一站式低代码 / 无代码 AI 应用开发平台，核心是让不会编程的人也能快速做出可用的 AI 应用。
简单讲：用拖拽 + 工作流配置，像搭积木一样做 AI 智能体和工具，不用写复杂代码

# 5 能做什么
网站，小程序，app。。。
拖拽设计前端界面（表单、按钮、输入框）
后端逻辑由【工作流】驱动，不用写代码
一键发布为独立网页，小程序
典型场景：拍照答题小程序，换脸小程序，记账软件，创作ppt的软件，抖音文案转小红书应用


# 6 典型应用场景
企业：智能客服、内部知识助手、数据报表自动化、培训机器人
自媒体 / 营销：文案生成、短视频脚本、热点追踪、直播问答
教育：AI 答疑、作文批改、题库生成、试卷生成，拍照答题。。。
个人：会议纪要、旅行规划、简历优化、论文助手
电商：售前推荐、售中查单、售后 FAQ、评价分析

# 7 一句话总结
Coze = 免费可视化 IDE + 大模型调度 + RAG 知识库 + 插件系统 + 多渠道发布【网站，小程序】。它把 AI 开发从 “专业程序员专属” 变成 “人人可上手”---》纯小白可以实现专业程序员写软件
```

### 4.3.3 代码节点

```python

# 0 工作流中任何节点：大模型，插件，查询数据。。。。
	-输入
    -输出
# 1 判断如果上面能查到结果
	-返回：登录成功
    
# 2 判断如果上面没有结果
	-返回：用户名密码错误
    
# 3 输入：
	outputList---》这个变量---》列表：[元素1，]--->长度大于0，表示有这个用户，否则，没有用户
# 4 输出：
	out   登录成功  或  用户名密码错误
	
# 5 代码：模板：
async def main(args: Args) -> Output:
    # 1 输入：从这里拿
    params = args.params 
    
    # 爱写什么写什么
    
    
    # 2 输出得这样写
    ret: Output = {
        'out':'123'
    }
    return ret

# 6 都在上面的模版上改代码
async def main(args: Args) -> Output:
    params = args.params # params当成一个包裹，里面放了很多东西：有outputList等等
   
    # 1 取出传入的变量：outputList，固定写法
    outputList=params['outputList']
    # 2 判断outputList 长度
    if len(outputList)>0:
        out='登陆成功'
    else:
        out='用户名密码错误'
        
    ret: Output = {
        'out':out
    }
    return ret


# 现在几乎所有软件，不会有  用户名正确，密码错误的提示
	lqz ---》密码错了--》撞库---》只要次数足够多---》就能破解别人密码
    用户名密码错误：用户不知道是否有这个用户还是密码错了
   	用户不在：用户名不存在
    用户存在，密码错误：密码错误
```
