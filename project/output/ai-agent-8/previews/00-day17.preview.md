# 1 服务器安装nginx

```python
# 1 nginx软件：反向代理软件
	-1 请求转发：把用户的请求--》转发给django项目
    -2 代理静态资源：直接访问图片，js，css--》nginx速度特别快
    	-飞机大战，就是利用了这个特性：js，css，html--》静态文件
    -3 负载均衡
    	-可以提高项目的并发人数
        -1000来个用户同时使用没问题---》分流
        
    -明白：请求发送到nginx上后---》转发给 django项目
    -为什么要有转发：因为nginx性能高--》可以抗住特别多用户访问--》如果没有它，用户访问量大，项目会崩
    	理发店：同时理发5个人
        500个人--》nginx---》慢慢的5个，5个的进到理发店中理发
```

```python
# 1 前往用户根目录
cd 

# 2 下载nginx 1.28.0
wget https://nginx.org/download/nginx-1.28.0.tar.gz
#3 解压安装包
tar -xf nginx-1.28.0.tar.gz

#4 进入目标文件
cd nginx-1.28.0

# 5 配置安装路径：/usr/local/nginx
# 安装 PCRE 开发包的名称是 pcre-devel，支持https访问
#zlib-devel：用于 gzip 压缩模块。openssl-devel：用于 SSL/TLS 模块（如启用 HTTPS） gcc 和 make：编译工具链
dnf install -y pcre-devel gcc make zlib-devel openssl-devel
./configure --prefix=/usr/local/nginx --with-http_ssl_module
#6 编译并安装
make &&  make install

# 7 建立软连接：终端命令 nginx
ln -s /usr/local/nginx/sbin/nginx /usr/bin/nginx 

#8 删除安装包与文件：

rm -rf nginx-1.28.0.tar.xz
```
