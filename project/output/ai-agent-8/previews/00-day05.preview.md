## 1.1 分析

```python
# 1 注册功能--》用户输入：用户名，密码，确认密码
	-1 最简单的---》之间吧用户名和密码存入数据库
    	lqz--》123456--》注册成功
        lqz--》56789---》注册成功
        相同用户名不允许多次注册
    -2 升级版：用户名，密码---》先根据用户名查询用户
    		-1 查到用户了 ---》不能再注册了
            -2 没查到用户 ---》存入数据库
          结束
    -3 比较两次密码一致性：放
    
# 2 工作流拆分
	1 开始节点
    	-用户名，密码，确认密码
    2 查询数据库：根据用户名查询
    3 如果查到了用户---》进入代码节点
    4 如果没查到用户---》存入数据库---》进入代码节点
    5 代码节点【无论是否有用户，都会走进来】
    6 结束
```

### 1.2.5 代码节点

```python
# 1 代码节点的作用
	-判断是注册成功用户，还是用户已经存在了不能注册了，输出给结束节点

# 2 输入和输出
	输入： 上一个节点：新增数据的行数--》row
    输出：---》out
    	注册成功
        用户已经存在
        
# 3 代码--》模板
async def main(args: Args) -> Output:
    params = args.params
    row=params['row']
    ret: Output = {
        "out":'',   # 输出一个值：out
    }
    return ret

# 4 编写逻辑：通过判断 传入的row，如果大于0，表示新增了一个用户，否则，表示用户已经存在不能注册
		一种情况是 row 为 1 --》表示新增了一个用户--》走的是注册用户的分支
		否则，走的是不注册用户的分支--》表示 用户已经存在不能注册
		
        问题：可能没有row这个值
        	-如果没有row，这样去取row=params['row'] 就会报错


# 5 最终代码
async def main(args: Args) -> Output:
    params = args.params
    row=params.get('row',0)  # 去包裹中取row，如果有，就取出来，如果没有，取出0来
    # row=字典.get('row',0) 在值为 None 时，返回提供的缺省值。
    if row >0:
        out='注册成功'
    else:
        out='用户已经存在'
    ret: Output = {
        "out":out,   # 输出一个值：out
    }
    return ret

# 6 高级版：多数看不懂
async def main(args: Args) -> Output:
    params = args.params
    ret: Output = {
        "out":'注册成功' if params.get('row',0) >0 else '用户存在'
    }
    return ret
```

### 3.1.1 加入两次密码是否一致的代码节点

```python
import time
async def main(args: Args) -> Output:
    params = args.params
    password=params.get('password','password')
    re_password=params.get('re_password','re_password')
    if password==re_password:
        out='继续执行' # 如果两次密码一致--》继续执行
    else:
        time.sleep(1) # 如果两次密码不一致，停顿了1s--》让工作流中断
    ret: Output = {
        "out": out
   
    }
    return ret
```
