### 1.1.4 官方登录和纯API模式

```python
# 1 两种模式区分

## 官方登录模式
上游固定为 OpenAI 官方原生接口（Responses 协议）
不需要填写 API Key
请求直连 OpenAI 官方 Codex 服务
使用 ChatGPT 订阅额度（包月套餐:8美元，20美元，不是按量 API 计费）


## 纯 API 模式【为什么能使用中转站，使用国产模型原因】
上游是标准 OpenAI 兼容接口（Chat Completions）
自定义填入：BaseURL + API Key
	-OPENAI官方，不用填BaseURL，只需要填API key即可
    
支持：OpenAI 官方 API、DeepSeek、中转站点、本地 Ollama、通义千问等所有兼容接口。
不依赖 ChatGPT 账号，可以脱离 OpenAI 运行

# 本地 Ollama:自己本机性能很高，可以自行部署开源模型：deepseek，千问---》不需要花钱买token，走自己机器的算力---》2--5期都讲了，本地部署大模型



# 2 注意
## 官方登录模式
使用账号会话方式，OpenAI 风控严格，大量请求极易封号；
只能用 OpenAI 模型，无法接入 DeepSeek、本地模型；
消耗 Plus 包月额度，高频写代码很快耗尽每日限额；
网络门槛高，国内环境很难稳定连通。

## 纯 API 模式（绝大多数国内开发者首选）
可以填入 AI 中转站地址，灵活切换 Sol/Terra/Luna/ DeepSeek V4；
模型自由切换，可以低成本批量写代码；
关键设置：接入中转 / DeepSeek 时，上游协议必须切换为 Chat Completions，否则报错；
短板：Codex 部分官方专属插件、文件解析功能可能缺失
```
