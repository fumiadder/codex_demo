## 2.1 AI相关名词解释
```python
LM，LLM，ChatGPT，DeepSeek，豆包，LangChain，langGraph，RAG，Prompt，AI Agent，AIGC，Dify，coze，n8n，skill，functionCalling，MCP，Cursor，Trae，Codex，Claude code， openclaw/workbuddy

# 1 LM ：Large Model：大模型：指通过海量数据训练、参数量庞大的机器学习模型【Transformer】，具备强大的泛化能力和复杂任务处理能力--->有推理能力

# 2 LLM：Large Language Model，大型语言模型：理解和生成人类语言，实现对话交互、文本摘要、翻译，编程，生视频，生图等，作为构建智能应用的核心引擎

# 3 ChatGPT：就是LLM的具体应用，一款产品，提供自然流畅的人机对话，支持信息查询、创意生成、问题解答，ppt创作，视频生成。。。openai公司的产品

    -用代码开发AI产品：AI诊疗。。。。
    -框架，写代码
```
