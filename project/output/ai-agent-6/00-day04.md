# 1 OpenClaw 介绍

```python
# 1 OpenClaw（曾用名 ClawdBot、Moltbot）是一款开源、本地优先、可自托管的 AI 智能体执行网关，核心口号是 The AI that actually does things（真正能做事的 AI）。它不只是聊天，而是能直接操控你的电脑、执行真实任务的自动化助手

# 2 核心定位与本质
## 2.1 不是大模型：它本身不做 AI 训练，而是AI 的 “手脚” 与 “桥梁”。
## 2.2 一端连模型：接入 ChatGPT、Claude、Gemini、Ollama、通义千问、智谱 GLM 等几乎所有主流云端 / 本地大模型。
## 2.3 一端连设备：赋予 AI 访问本地文件、Shell、浏览器 的能力，实现自然语言→任务拆解→自动执行→结果反馈的全流程闭环。
## 2.4 本地优先：所有数据、记忆、日志存在你自己的设备 / 私有云，隐私完全可控。


#  3 能做什么
## 3.1 系统级操作
    文件管理：读写、编辑、批量重命名、整理文件夹、搜索文件。
    终端执行：运行 Shell 命令、安装软件、执行脚本、管理进程。
    浏览器自动化：打开网页、搜索、填表、点击、截图、数据抓取。
    桌面控制：模拟鼠标 / 键盘、识别 UI、操作无 API 的桌面软件。
## 3.2 多渠道交互
    IM 机器人：飞书、钉钉、微信等。
    本地入口：Web UI、CLI 命令行、全局快捷键唤出。
    API 接入：支持 HTTP API，可集成到自己的应用。
## 3.3 智能体能力
    持久记忆：跨会话保存你的偏好、项目细节、历史上下文。
    任务拆解：把复杂指令（如 “整理本月报表并发送给团队”）自动拆成步骤执行。
    异常处理：执行中遇到问题会自动重试、调整策略、向你确认。
## 3.4 可扩展生态
    Skills 技能市场（ClawHub）：官方 + 社区已提供超 1.1 万个技能插件，像装 App 一样扩展能力。
    办公：邮件收发、日程管理、文档生成、数据报表。
    开发：代码编写、调试、部署、API 调用。
    生活：智能家居、购物、股票、内容创作。

    
# 4 典型使用场景
    个人办公自动化：自动整理文件、发邮件、做周报、管理日程。
    开发者助手：写代码、跑脚本、部署服务、管理服务器。
    数据处理：批量爬取网页、清洗数据、生成报表。
    团队协作：通过 IM 机器人统一执行团队任务、同步信息。
    本地 AI 助理：控制电脑、智能家居、工作流。
```

## 7.3 配置openclaw

```python
# 1. 安装飞书插件
# 安装官方飞书渠道插件
npm install -g @openclaw/feishu
# 或直接在聊天框让openclaw装
帮我安装飞书插件

# 2 配置飞书（交互式向导）
# 启动渠道配置向导
openclaw channels add
# 按提示操作
    选择 Feishu/Lark (飞书)
    粘贴 AppID、AppSecret
    选择websocket   # 【下面解释】
    域名选择：Feishu (feishu.cn) - China（国内版）
    群聊策略（groupPolicy）：推荐 Open（需 @ 机器人）
    结束配置
    私聊策略（dmPolicy）：推荐 pairing（需配对）
```

# 9 Skills配置

```python
# 1 是什么？
Skill = 插件/功能包，让 OpenClaw 拥有真实执行能力
Tool = 器官（能不能做）；Skill = 教程（怎么做）
安装一行命令，不用写代码，不用懂原理

举个例子：龙虾无法下载b站的视频---》有个下载b站视频的skills---》装好后
通过给龙虾 自然语言--》让它下载b站视频，就可以下载


# 2 注意：
# 先装安全审查技能skills---》来历不明的skills，存在安全风险
# 再装基础能力（搜索、浏览器、记忆）
# 最后装场景技能（办公、开发、自媒体）
# 不用的技能及时关闭，避免卡顿与风险

# 2 国内比较好的一些skills

```

## 9.1 基础skills

```python
# 1. skill-vetter（安全审查官）
    作用：装任何技能前先扫描，防病毒、防偷数据
    命令：clawhub install skill-vetter
    必装理由：ClawHub曾查出341个恶意技能，这个是保命盾
# 2. clawhub（技能商店）
    作用：搜索、安装、管理所有技能
    命令：npm i -g clawhub
    地位：OpenClaw的应用商店，没有它无法扩展
# 3. tavily-search（AI专属联网搜索）
    作用：AI专用精准搜索，无广告、直接给结果
    命令：clawhub install tavily-search
    亮点：比百度/谷歌更适合AI读取，做总结、调研神器
# 4. agent-browser（浏览器自动化）
    作用：AI自己操控浏览器，点按钮、填表单、截网页、下文件
    命令：clawhub install agent-browser
    神技：自动抢票、监控价格、采集数据
# 5. self-improving-agent（自我进化）
    作用：AI越用越聪明，记住错误、优化流程、不重复踩坑
    命令：clawhub install self-improving-agent
    亮点：本地运行，不泄露隐私
# 6. agent-memory（永久记忆）
    作用：记住你的习惯、工作流、常用信息
    命令：clawhub install agent-memory
    效果：不用每次重复说明需求，AI秒懂你
# 7. summarize（万能总结）
    作用：PDF、网页、视频、长文一键提炼要点
    命令：clawhub install summarize
    效率：100页报告30秒读完
# 8. cron（定时任务）
    作用：每天/每周自动执行任务（早报、监控、发消息）
    命令：clawhub install cron
    场景：自动发日报、定时查资讯、监控网站
```
