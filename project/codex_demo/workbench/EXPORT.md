# 数据导出、自动快照与账号生命周期

本模块把「数据属于用户」做成产品内能力：空间所有者可随时导出自己的数据；服务器在本地保留每日数据库快照；用户可以自行修改资料、注销账号或删除空间。所有能力复用现有的账号会话、空间成员权限与 CSRF 校验，不引入第三方依赖。

## 模块边界与接线

- 导出与快照逻辑在 `export.py`，对外只暴露 `initialize(server)`、`dispatch(handler, path, query)`、`run_maintenance(server)`；由 `server.py` 在模块初始化、请求分发与低频维护路径 `maybe_cleanup` 中接线。
- 账号与空间生命周期（改资料、改密码、注销、删空间、撤权清理）直接实现在 `server.py`，与条目、成员路由共用同一套鉴权与写事务。
- 无数据库结构变化：不新增表、不改列，全部基于既有 `items`、`daily_*`、`bedtime_*`、`vaults`、`spaces`、`users`、`sessions`。

## 单空间导出

- 路由：`GET /api/spaces/:sid/export?format=json|markdown|html`，仅空间 **owner** 可调用；editor/viewer 返回 403，非成员 404，匿名 401。按账号限流每小时 6 次。
- 范围严格按 `space_id` 在 SQL 层绑定，包含该空间的条目（`meta` 原样）、文件元数据、今日记录与图片、每日摘要、成员信息，以及**当前调用者本人**在该空间的密码箱密文（导出标注 `locked: true`，恢复仍需原密码）。
- 永不导出：其他空间、其他用户的密码箱、会话、邀请码、密码哈希、任何密钥。
- 三种格式：
  - `json`：单个 `export.json` 加 `assets/` 私有媒体；
  - `markdown`：每条记录一个 `.md`，加 `INDEX.md` 与 `assets/`；
  - `html`：单个转义后的 `index.html` 加 `assets/`。
  - HTML 与 Markdown 都对用户文本做转义，归档路径与文件名走白名单，杜绝脚本注入与 zip-slip。
- 媒体文件通过私有存储接口 64KB 分块读入 zip；zip 先写到数据目录下的 0600 临时文件再流式下发，响应为 `application/zip`、`Cache-Control: private, no-store`、附件 `Content-Disposition`，请求结束清理临时文件。单个媒体缺失只在清单中标注，不毁整包。

## 自动快照（仅运维可见）

- `run_maintenance` 由认证流量驱动的维护路径调用，遵循项目「空闲实例不轮询」的约定；非阻塞锁，拿不到即跳过。
- 仅 SQLite 方言执行：用在线备份 API 生成 `DATA_DIR/snapshots/folio-<时间戳>.db`，目录 0700、文件 0600；PostgreSQL 由外部备份体系负责，本函数直接返回。
- 每天最多一份（按文件名日期去重），保留最新 7 份，更旧的自动清理；任何异常只告警、不影响请求线程。
- 快照是**全库文件，包含所有用户数据**，因此不提供任何 HTTP 下载路由，只能由服务器运维通过受控环境访问。用户侧的数据可携带能力是上面的单空间导出。
- 备份在隔离临时目录完成并把日志模式收敛为单文件后原子落位，避免 WAL sidecar 导致备份缺最新页。

## 账号与空间生命周期

- `PATCH /api/me`：改昵称；或用 `{password:{currentPassword,newPassword}}` 改密码。改密码先校验当前密码，成功后删除该用户全部会话并在响应中下发新 Cookie，旧会话立即失效。
- `DELETE /api/me/account`：需再次提供登录密码。若仍拥有含其他成员的空间，或在他人空间留有共享记录（`created_by` 无外键级联），返回 409 引导先处理；否则把私有媒体对象全部入删除队列后级联删除空间与账号，并清除当前 Cookie。
- `DELETE /api/spaces/:sid`：仅 owner；仍有其他成员时 409；媒体对象先入队再级联删除空间。
- 移除成员（撤权）：删除其在该空间的晚安故事收藏、阅读历史、克隆音色、私有朗读音频与密码箱副本，落实「撤权清除生成故事和阅读状态」；条目与今日记录属于共享空间资产，保留给其余成员。远程音色在提交事务后按既有规则尽力清理，无密钥或厂商失败不阻断撤权。
- 所有对象删除都先在写事务内写 `storage_jobs` 删除队列、再删数据库行，实际对象 I/O 在提交后执行，失败可重试且不会留下孤儿引用。

## 验证与降级

- 后端 `tests/test_export.py` 覆盖三种格式、权限矩阵、跨空间零泄露、转义、限流、快照幂等与留存、PostgreSQL 跳过与异常不抛出；账号与空间生命周期用例在 `tests/test_server.py`。
- 浏览器 `scripts/account_export_qa.py` 走真实 HTTP 服务，覆盖改资料/改密码、三格式导出 zip 校验、非 owner 拒绝、删空间 409 到成功、账号注销后会话失效与窄屏适配。
- 缺少外部密钥不影响导出与快照；存储后端异常时导出返回脱敏 503，快照仅告警，不破坏在线服务。
